<h1>Undertale Fanmade Website as Assessment for Course</h1>

</br>This website is a fanmade tribute to Undertale, the indie game released in 2015 that I've enjoyed for many years. Created by a beginner learning web development, 
the site has three pages: the main page explains why I love the game and its unique gameplay choices, 
the second page shares fun facts and introduces classic characters like Sans, Papyrus, and Toriel, 
and the third page displays a collection of Undertale memes that keep the game popular online. 
</br>
As a beginner project, the site celebrates nearly 10 years of Undertale's lasting impact on gaming culture 
and its dedicated fanbase while showcasing my journey in learning HTML and CSS.
</br>
